# Portfólio Enzo

Portfólio com frontend impactante, animações fluidas e design diferenciado para cativar clientes.

## ✨ Destaques

- **Hero cinematográfico** – Texto revelado com animação, partículas e gradientes
- **Cursor customizado** – Efeito magnético em links e botões (desktop)
- **Animações no scroll** – Seções aparecem suavemente ao rolar
- **Cards de projetos** – Hover com glow e micro-interações
- **Tipografia Syne + DM Sans** – Visual moderno e único

## 🚀 Como rodar

```bash
npm install
npm run dev
```

Acesse [http://localhost:5173](http://localhost:5173)

## 📝 Personalize

1. **Contato** – Edite `src/components/Contact.jsx` com seu e-mail, LinkedIn e GitHub
2. **Projetos** – Atualize o array em `src/components/Projects.jsx` com seus projetos reais
3. **Sobre** – Ajuste o texto em `src/components/About.jsx`
4. **Nome** – Troque "Enzo" em `Hero.jsx` e `Navbar.jsx` se necessário
